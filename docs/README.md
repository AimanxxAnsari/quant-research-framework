# Documentation index

| Folder | Contents |
|---|---|
| [`projects/`](projects/) | Write-ups per pillar in short-paper form |
| [`design/`](design/) | Design docs: purpose, interfaces, invariants, edge cases, test plan |
| [`decisions/`](decisions/) | Decision records (ADRs), including rejected options |
| [`devlog/`](devlog/) | Dated session logs: what was done, bugs (symptom -> cause -> fix), next steps |
| [`learning/`](learning/) | Concept notes |
| [`interview/`](interview/) | Pitch, walkthrough, likely questions, things to rebuild from scratch |

Docs are written in the same session as the code; dates match git history; accepted decisions are
superseded by new ADRs rather than edited.
