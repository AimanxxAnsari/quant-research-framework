## Bugs / issues (symptom -> cause -> fix)
- Robust variance-ratio z* came out ~140x too small -> theta is the asymptotic variance of
  sqrt(T)(VR - 1), and I divided by sqrt(theta) instead of sqrt(theta / T) -> fixed; caught by the
  AR(1) known-answer test (z* must be large when rho = 0.3).
- Non-synchronous correction returned 0.57 instead of ~1 on the simulated factor model -> I summed
  lagged *returns* then correlated, which adds noise from irrelevant lags -> switched to summing
  lagged *covariances* (Scholes-Williams / Dimson style).
- First Hurst test used AR(1) rho = 0.5 and expected R/S > 0.6 -> the effect is real but smaller
  (0.58) -> test now compares against the shuffled baseline (3 sd) with rho = 0.7.
- Draft commentary claimed EWJ "shows no such lag" -> data shows -0.10 next-day correlation
  (reversal while Tokyo is closed) -> commentary is now generated from the numbers with sign- and
  significance-aware wording (|corr| > 3/sqrt(n)).
