## Bugs / issues (symptom -> cause -> fix)
- OVX failed the range check (226 on 2020-04-20) -> bound of 200 too tight for a real event
  (negative WTI day) -> widened to 500 with a comment.
- "new snapshots" count in `qrf fetch` was wrong -> compared timestamps of returned snapshots,
  which for unchanged data are the old ones -> count new `stored` events in the manifest.
- Package source folder `src/quant_research/data/` was missing from the first staged commit ->
  `.gitignore` rule `data/` matches a folder named `data` at any depth -> anchored to the repo root
  (`/data/`); caught by reviewing the staged file list before committing. Side effect: ruff also
  skips git-ignored files, so the package had never been linted locally; CI caught one unsorted
  import on the first push, fixed in the next commit.
- French library returned HTTP 403 to the framework's descriptive User-Agent -> server-side
  filtering; robots.txt does not disallow the data folder and generic clients receive the file ->
  **open**: deliberately not worked around by changing identities; options are a manual download
  into the raw store, or asking the library maintainers.
